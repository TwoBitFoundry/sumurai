# Copy Rewrite List

Use this as a working draft for rewriting the current app copy page by page.

Focus on the philosophy of the samurai: stoicism, absolute precision, internal mastery, and unyielding honor. In a financial context, this translates to treating money not as something to stress over, but as an energy to be mastered through calm intent, disciplined habits, and total clarity.
